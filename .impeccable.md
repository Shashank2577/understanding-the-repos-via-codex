## Design Context

### Users
The repository owner, developers onboarding to these projects and coding assistants carrying work across sessions. They need to compare product intent, implementation evidence, gaps and next investments without reading twenty source trees.

### Brand Personality
Calm, precise, editorial. User selected “Calm editorial style.” Establish confidence through visible evidence and clear uncertainty rather than decorative scores.

### Aesthetic Direction
Use Cairn’s existing survey-map paper/ink palette and Overpass typography as the primary design source. Broad whitespace, ruled sections, readable comparison tables, restrained category colors. Real screenshots retain each app’s original design. Static HTML should work offline and on GitHub Pages.

### Design Principles
- Lead with decisions and concrete user jobs.
- Separate observed implementation from proposals.
- Link summaries to durable Markdown and source evidence.
- Make comparisons usable on small screens and with a keyboard.
- Show actual UI when available and label historical assets.
